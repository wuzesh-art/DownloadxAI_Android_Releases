# downloadxAI — Android

Official Android download portal for downloadxAI.

This repository contains signed release binaries only. Source code is not
published here.

## Download

Grab the latest APK for your device architecture from the
[Releases](https://github.com/wuzesh-art/DownloadxAI_Android_Releases/releases)
page:

- `arm64-v8a` — modern 64-bit devices (recommended)
- `armeabi-v7a` — older 32-bit devices

Installed apps stay up to date through the in-app update check.
